SPD Dental — Multi-Branch Operations Dashboard

A star-schema Power BI platform built on custom Power Query (M) against the Curve Dental API, surfacing production, appointments, and unscheduled treatment value across branches. All figures shown are synthetic; no real patient, provider, or financial data is included.

01 / The Challenge

Recoverable revenue was invisible across branches

SPD Dental's practice management software tracked patients, appointments, treatment plans, and ledger transactions, but had no reporting layer connecting any of it across locations. Each branch's data lived in its own silo inside the practice management system.

The biggest gap: front-desk teams had no visibility into treatment plans that were proposed but never scheduled. That's recoverable revenue sitting untracked, branch by branch, with no way to see it without manually cross-referencing systems.

02 / Approach

A direct API pipeline into a governed data model

I built a pipeline pulling directly from the Curve Dental API using custom Power Query (M), with OAuth2 client-credentials authentication, token refresh, and paginated pulls handled in code. No manual exports, no CSV wrangling.

The data is modeled into a star schema: Appointments, LedgerEntries, TreatmentPlans, and Notes as fact tables, joined against Patients, Staff, and Clinics dimensions plus a standard date table. DAX measures on top handle production, reappointment rate, treatment-plan acceptance, and no-show tracking.

03 / What's In the Platform

From practice overview to a direct call list

Three views cover the day-to-day work, from a portfolio-level read on the practice down to a list a front-desk employee can act on immediately:

  • Practice Overview production, appointments, and patient acquisition across all branches in one place
  • Appointments & Treatment Plans appointment volume, treatment-plan acceptance rate, and no-show or cancellation tracking
  • Unscheduled Treatment Tracker a dedicated table surfacing proposed-but-not-booked treatment value, built as a direct call list for front-desk staff

04 / Result

From no visibility to a direct action list

Front-desk teams went from no visibility into unscheduled treatment value to a governed, self-service Power BI environment covering appointments, production, and patient acquisition across every branch. What used to be manual, branch-by-branch spreadsheet reporting now runs from a single model everyone pulls from.
