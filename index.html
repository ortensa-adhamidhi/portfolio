Wotels — Multi-Property Reporting
🚧 Case study in progress
Hospitality · Freelance · Power BI + Mews API
Challenge

Wotels runs 18 properties plus head office, but occupancy, financial actuals, and budgets each lived in a different system — Mews, Primavera ERP, and Excel — with no unified view of performance by property or department.

What I did

Built a star-schema Power BI model unifying all three sources: custom M functions call the Mews API for occupancy, a SQL connection pulls P&L actuals from Primavera, and Excel budgets feed the same fact table — with DAX variance/YTD measures and row-level security by property.

Result

Five linked reports — portfolio KPIs, Units and Overhead P&L, variance drill-downs, and executive summaries — replacing a manual monthly close across three systems.
